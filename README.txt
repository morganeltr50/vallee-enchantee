VALLÉE ENCHANTÉE V5 — APPLICATION COMPAGNON NON OFFICIELLE

MISE À JOUR DEPUIS V1–V4 :
1. Dans l’ancienne application, Mes données > Exporter. Conserver la sauvegarde JSON.
2. Décompresser ce ZIP dans Fichiers sur iPhone.
3. Remplacer sur GitHub Pages (branche main, racine) : index.html, sw.js, icon.svg, manifest.webmanifest.
4. Ouvrir le site. Si l’ancienne interface reste visible, fermer/réouvrir l’application ou recharger Safari.
5. Les clés de sauvegarde locales restent inchangées : vallee-enchantee-v1.
6. Si besoin, Mes données > Importer et choisir la sauvegarde JSON. Compatibilité import V1–V5.

V5 ajoute une bibliothèque de sources consultables en ligne, une recherche ciblée et des liens de vérification sur les fiches. Elle ne contient PAS l'intégralité des quêtes, recettes, meubles, vêtements, biomes ni données de temps de réapparition. Des sources communautaires peuvent se contredire. Le catalogue local est partiel.

Sources : https://dreamlightvalleywiki.com/Critters ; /Gardening ; /Cooking ; /Quests ; /Characters ; /Ingredients et https://disneydreamlightvalley.com/fr
